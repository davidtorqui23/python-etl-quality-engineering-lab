# ADR-001

Decision:

Use Story Driven Quality Engineering.

Reason:

Improve traceability.

Impact:

All implementation must originate from a User Story.

---

# ADR-002

Decision:

Introduce Step Catalog.

Reason:

Avoid duplicated Gherkin vocabulary.

Impact:

All features must reference approved steps.

---

# ADR-003

Decision:

Delivery Manager becomes lifecycle orchestrator.

Reason:

Reduce manual execution.

Impact:

Single entry point for new stories.
